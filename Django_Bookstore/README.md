
# Django Bookstore

Django Bookstore - навчальний вебзастосунок інтернет-магазину книг, розроблений на Python та Django.

Проєкт реалізує каталог книг, категорії, авторизацію користувачів, кошик покупок, оформлення замовлень та тестову оплату через Stripe.

## Технології

- Python 3.14
- Django 6.1
- PostgreSQL
- Redis
- Docker та Docker Compose
- Stripe API
- pytest, pytest-django, pytest-cov
- factory-boy

## Функціональні можливості

- Перегляд каталогу книг.
- Фільтрація книг за категоріями.
- Перегляд детальної інформації про книгу.
- Реєстрація та авторизація користувачів.
- Додавання, редагування та видалення книг відповідно до прав доступу.
- Додавання та видалення книг із кошика.
- Оформлення замовлень.
- Тестова оплата через Stripe Checkout.
- Підтвердження замовлень електронною поштою.
- Підтримка української та англійської мов.
- Асинхронні Django views для роботи з базою даних.

## Запуск проєкту

### 1. Клонування репозиторію

```bash
git clone https://github.com/Freshenup4958/PythonProject.git
cd PythonProject/Django_Bookstore
```

### 2. Налаштування змінних середовища

Створити файл `.env` у папці `Django_Bookstore` та налаштувати необхідні змінні середовища, зокрема параметри PostgreSQL, Django та тестові ключі Stripe.

Секретні ключі не повинні зберігатися в Git-репозиторії.

### 3. Запуск Docker

```bash
docker compose up --build -d
```

### 4. Застосування міграцій

```bash
docker compose exec web python manage.py migrate
```

### 5. Відкриття сайту

Після запуску вебзастосунок доступний за адресою:

http://127.0.0.1:8000/

## Тестування

Для автоматизованого тестування використовуються pytest-django, factory-boy та unittest.mock.

### Запуск усіх тестів

```bash
pytest -q
```

### Перевірка покриття коду

```bash
pytest --cov=books --cov=accounts --cov-report=term-missing
```

Під час перевірки було успішно виконано 35 тестів:

- 20 unit-тестів.
- 15 integration-тестів.

Покриття коду становило 94%.

Зовнішні сервіси Stripe та email тестуються з використанням mock-об'єктів.

### Code Review

За допомогою ChatGPT проведено аналіз трьох Django views:

1. `order_create` - створення замовлення.
2. `payment_process` - створення платіжної сесії Stripe.

Під час аналізу виявлено проблеми з відправленням електронної пошти, перевіркою стану замовлень, обробкою помилок Stripe API та підтвердженням платежів.

Після перевірки рекомендацій внесено відповідні зміни до коду.
