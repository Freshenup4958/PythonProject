
# AI Prompts - Django Bookstore

## Використаний інструмент

ChatGPT (OpenAI)

## 1. Code Review

### Prompt 1

Проаналізуй функцію `order_create` у Django-проєкті.
Знайди потенційні помилки в роботі з транзакціями,
кошиком та відправленням email.
Запропонуй покращення коду з поясненнями.

### Prompt 2

Проведи Code Review функції `payment_process`,
яка створює Stripe Checkout Session.
Перевір обробку помилок, SQL-запити,
перевірку статусу замовлення та формування URL.

### Prompt 3

Перевір функцію `payment_success`.
Знайди проблеми з підтвердженням платежів,
обробкою помилок Stripe API та перевіркою
суми й валюти транзакції.

## 2. Генерація та покращення тестів

### Prompt 4

Допоможи створити unit-тести та integration-тести
для Django Bookstore за допомогою pytest-django
та factory-boy. Використовуй mock для Stripe API
та відправлення електронної пошти.

### Prompt 5

Після додавання `transaction.on_commit()` тест
відправлення email не проходить.
Поясни причину та запропонуй правильний спосіб
тестування callback-функцій у pytest-django.

### Prompt 6

Онови інтеграційні тести Stripe Checkout
після додавання перевірок наявності товарів,
статусу оплати, суми та валюти платежу.

## 3. Перевірка результатів

### Prompt 7

Перевір, чи відповідають зміни вимогам завдання.
Допоможи запустити pytest, перевірити coverage
та підготувати документацію використання ШІ.

## Висновок

ChatGPT використовувався для аналізу коду,
пошуку потенційних помилок, формування рекомендацій
та допомоги з тестуванням.

Запропоновані зміни були переглянуті,
адаптовані до структури проєкту та перевірені
автоматизованими тестами.
